## Tips:
- Foto: PNG atau JPG, minimal 800×500px
- Video: MP4 (H.264), resolusi 1280×720 atau lebih, ukuran idealnya < 30MB
- Thumbnail (opsional): PNG/JPG dengan ukuran sama seperti video untuk preview sebelum play
- Setelah file ditaruh, langsung tampil tanpa edit kode
